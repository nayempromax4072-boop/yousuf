## 1. Project Overview

Yusuf Electronics is a production-ready Android application integrating both a **Customer Panel** and a role-protected **Admin Panel** inside a single APK backed by Firebase:

- **Customer Panel:**
  - Animated Splash Screen & Bilingual Welcome / Google Sign-In Onboarding (`বাংলা` / `English`)
  - Customer Home Dashboard with Service Search, 10 Technical Service Categories (Fan, Motor, AC, LED, Wiring, CCTV, Plumbing, Building Electrical, Building Maintenance, Other), prominent **BOOK A SERVICE** CTA, Order Tracking strip, Notifications, and Shop Contact Card
  - Detailed Service Request Form with Photo Picker attachments, Video upload (<= 20 MB), preferred date & time slots, and auto-generated Order ID (`YE-YYMMDD-XXXX`)
  - Real-time Order Lifecycle Tracking (`Pending` → `Accepted` → `Contacted` → `Work Scheduled` → `In Progress` → `Completed` / `Cancelled`)
  - Real-time 1:1 Customer-to-Admin Live Chat supporting Text, Compressed Photos, Videos, and in-app Voice Recording & Playback with read receipts and retry handling
  - Customer Profile management with order stats, photo updates, language switcher, Privacy Policy, and About Us
- **Admin Panel (`nayempromax4072@gmail.com`):**
  - Live Dashboard Statistics (Total Customers, Total Requests, Pending, Accepted, Active Jobs, Completed Jobs, Unread Messages)
  - Customer Directory with search, profile details, order history, and direct chat launch
  - Order Management with search by Order ID, category/status filters, attachment inspection, appointment scheduling, BDT billing/estimate, internal notes, and status updates
  - Live Chat Inbox & Media Reply Console
  - Service Category Manager (Add, Edit, Activate/Deactivate, Delete)
  - Targeted Notification & Shop-Wide Announcement Broadcaster
  - Business Settings Manager (Shop Name, Tagline, Phone, Email, Address, Hours, Service Availability toggle)

## 2. Installation Instructions (Development)

1. Install **Android Studio (Ladybug or newer)** with **JDK 17** and **Android SDK 36**.
2. Clone your repository:
   ```bash
   git clone <your-repo-url>
   cd <repo-folder>
   ```
3. Ensure `app/google-services.json` is placed inside `app/` (do **not** commit sensitive production keys or keystores to public repositories).
4. Open the project in Android Studio and let Gradle sync.

## 3. Firebase Setup Instructions

1. Open the [Firebase Console](https://console.firebase.google.com/) and select your provisioned Firebase project (`gen-lang-client-0330658777` or your own project).
2. **Authentication:**
   - Enable **Google** sign-in provider under **Authentication → Sign-in method**.
   - Register your debug and release SHA-1 / SHA-256 keystore fingerprints in **Project Settings → Your Apps → Android (`com.yusufelectronics.service`)**.
   - *(Optional)* If you wish to add Email/Password login later, enable Email/Password under Sign-in method.
3. **Cloud Firestore:**
   - Confirm the named Firestore database ID matches `app/src/main/res/values/firebase_applet_config.xml`.
   - Deploy security rules from `firestore.rules`:
     ```bash
     firebase deploy --only firestore:rules
     ```
4. **Firebase Storage (Required for Photo, Video, and Voice Uploads):**
   - In Firebase Console, click **Storage → Get Started** to initialize the Storage bucket.
   - Deploy `storage.rules`:
     ```bash
     firebase deploy --only storage
     ```
5. **Firebase Cloud Messaging & Cloud Functions (Background Push Notifications):**
   - Deploy `functions/index.js` on a Blaze plan project to enable server-side FCM push triggers and custom claims:
     ```bash
     cd functions && npm install && cd ..
     firebase deploy --only functions
     ```

## 4. Firebase Configuration Files

- `app/google-services.json` — Android Firebase app configuration (generated by Firebase / AI Studio).
- `app/src/main/res/values/firebase_applet_config.xml` — Contains `firestore_database_id`.
- `firestore.rules` — Zero-trust role-based security rules enforcing strict per-customer isolation and verified admin access.
- `storage.rules` — Enforces MIME-type and file size restrictions (5 MB images/audio, 20 MB video).
- `firebase-blueprint.json` — Schema blueprint for all Firestore entities.

## 6. How to Build the APK

### Local Release APK Build
1. Generate an upload keystore (once):
   ```bash
   keytool -genkey -v -keystore my-upload-key.jks -keyalg RSA -keysize 2048 -validity 10000 -alias upload
   ```
2. Export keystore environment variables and build:
   ```bash
   export KEYSTORE_PATH="$(pwd)/my-upload-key.jks"
   export STORE_PASSWORD="your-store-password"
   export KEY_PASSWORD="your-key-password"
   ./gradlew assembleRelease
   ```
   Output APK: `app/build/outputs/apk/release/app-release.apk`

### GitHub Actions Automated APK Build
1. In your GitHub repository, go to **Settings → Secrets and variables → Actions** and add:
   - `GOOGLE_SERVICES_JSON_BASE64`: Base64-encoded `app/google-services.json`
   - `RELEASE_KEYSTORE_BASE64`: Base64-encoded `my-upload-key.jks`
   - `STORE_PASSWORD`: Keystore password
   - `KEY_PASSWORD`: Key alias password
2. Push to `main` or manually trigger **Build Yusuf Electronics Android APK** under the **Actions** tab.

## 7. How to Download and Install the APK

1. Open your GitHub repository's **Actions** tab (or **Releases** page).
2. Click the latest successful workflow run and download `yusuf-electronics-release-apk` (or `yusuf-electronics-debug-apk`).
3. Unzip the downloaded artifact and transfer the `.apk` file to your Android device.
4. On the Android device, open the `.apk` file, allow **Install from unknown sources** for your file manager/browser if prompted, and tap **Install**.
